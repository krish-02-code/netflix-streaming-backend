How it works:
Content Svc — calls GET /api/v1/movies/{movieId} on Content Service (:8081) → reads the stored hlsUrl from MySQL → streams via hls.js. Requires S3 public read access on the encoded/ folder.

Streaming Svc — calls GET /api/v1/stream/{movieId} on Streaming Service (:8084) → generates a fresh AWS presigned URL (valid ~60 min) → streams via hls.js. Works with private S3 buckets.

Direct URL — paste any publicly accessible .m3u8 URL and play immediately (no backend call needed).
